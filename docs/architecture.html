CLAM — CL Agent Mesh

Distributed AI agents, one shared workspace. Every machine runs its own OMP agents behind a loopback web UI; machines pair through Cloudflare Tunnels and work together over Ed25519-signed requests — group chat, task delegation, shared sessions, handoffs and shared memory.

Local-first · SQLite on every machine
2 listeners · 1 server process
1 OMP process per active session
Ed25519-signed node-to-node API
No control plane · pairing is machine to machine
